## Data Source

The dataset was obtained from the
[PokeAPI GitHub repository](https://github.com/PokeAPI/pokeapi).

The following CSV files were used in the project:

- `pokemon.csv`
- `pokemon_stats.csv`
- `pokemon_types.csv`
- `pokemon_species.csv`
- `types.csv`

The CSV files were imported into Google BigQuery and used as
the raw data sources for the analysis.


## Data Import

The CSV files were imported into Google BigQuery and stored in:
